# Credit Risk Modelling
Developed a predictive Probability of Default (PD) model on 2.2M+ consumer loan records using Logistic Regression, achieving  AUC 0.70; applied rigorous feature engineering to prevent data leakage.  Estimated LGD, EAD, and portfolio-level Expected Credit Loss under IFRS 9, built a points-based credit  scorecard using WOE/IV and Power BI dashboard.
